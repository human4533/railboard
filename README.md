# 🚆 레일보드 (열차 안내판)

역과 시간대를 고르면 **그 시간에 어떤 열차가 서는지** (종류·열차번호·행선지·도착/출발 시각) 보여 주는 웹 프로그램입니다.

| 구분 | 노선 | 데이터 |
|---|---|---|
| 간선 | 경부선, 경부고속선, 호남선, 호남고속선, 전라선, 강릉선 | 국토교통부 TAGO 열차정보 |
| 도시철도 | 수도권(서울·인천), 부산, 대구, 광주, 대전 전 노선 | 철도산업정보센터(KRIC) 열차별 운행시각표 |
| 실시간 | 수도권 전철 | 서울 열린데이터광장 실시간 도착정보 |

## 0. 친구들과 공유하기 (가장 쉬운 방법)

- **윈도우**: `start_windows.bat` 더블클릭 → 처음엔 cloudflared 설치 후 창을 닫고 한 번 더 실행
- **맥**: `start_mac.command` 우클릭 → 열기

검은 창에 `https://xxxx.trycloudflare.com` 주소가 나오면 그 주소와 비밀번호를 친구들에게 보내세요.
- 비밀번호는 `config.json` 의 `"password"` 입니다. 접속하면 로그인 창이 뜨는데 **아이디 칸은 아무거나**, 비밀번호 칸에 이 값을 넣으면 됩니다.
- PC를 끄거나 창을 닫으면 접속이 끊기고, **다시 켤 때마다 주소가 바뀝니다.** 새 주소를 다시 알려 주세요.
- 비밀번호를 비우면(`""`) 주소를 아는 누구나 들어올 수 있으니 꼭 넣어 두세요.

## 1. 실행 (설치할 것 없음)

파이썬 3.9 이상만 있으면 됩니다.

```bash
cd train_board
python server.py
```

브라우저에서 **http://localhost:8000** 을 엽니다. 같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:8000` 으로 열 수 있습니다.

인증키가 없으면 **데모 모드**(예시 데이터)로 열려서 화면부터 확인할 수 있습니다.

## 2. 인증키 받기 (모두 무료)

`config.example.json` 을 복사해 `config.json` 으로 이름을 바꾸고 키를 넣으세요.

1. **data_go_kr_key**: data.go.kr에서 「국토교통부_(TAGO)_열차정보」 활용신청 → 마이페이지의 *일반 인증키(Decoding)*
2. **kric_key**: data.kric.go.kr(레일포털) → Open API → 「열차별 운행시각표」, 「열차별 운행시각표(급행)」, 「도시철도 전체노선정보」 활용신청
3. **seoul_key**: data.seoul.go.kr → 「서울시 지하철 실시간 도착정보」 인증키 신청 (선택)

키는 신청하고 승인되기까지 몇 시간에서 하루쯤 걸릴 수 있습니다.

## 3. 동작 방식

- **간선**: 고른 역에서 같은 노선의 다른 모든 역까지 양방향으로 TAGO를 조회하고, 열차번호로 합쳐 도착·출발 시각과 시발/종착역을 만듭니다.
- **도시철도**: KRIC 역별 시간표를 쓰고, 옆 역 시간표와 비교해 방면(상·하행)을 계산합니다. 평일·토요일·휴일(공휴일 포함) 시간표를 자동으로 고릅니다.
- 역 목록은 처음 한 번 받은 뒤 `cache/` 폴더에 30일 동안 저장합니다. 노선이 바뀌었으면 `http://localhost:8000/api/refresh` 를 열어 새로 받으세요.

## 4. 알아 둘 점

- 코레일 간선 열차의 **실시간 위치/지연**은 공개 API가 없어서 계획 시각만 나옵니다.
- 실시간 도착은 **수도권만** 됩니다. 다른 도시는 시간표 기준입니다.
- TAGO는 대략 **30일 이내** 날짜만 조회됩니다.
- KRIC 권역코드 03~05(대구·광주·대전)는 추정값입니다. 노선이 안 나오면 `config.json` 에 `"urban_regions"` 를 넣어 고칠 수 있습니다.
- 간선 역 이름이 TAGO와 달라 경고가 뜨면 `config.json` 의 `"intercity_lines"` 로 역 목록을 덮어쓸 수 있습니다.

## 5. 차량 이름 (KTX-1, 와인산천 등)

- 공공 API는 **열차 등급**(KTX, KTX-산천, KTX-이음, KTX-청룡, ITX-새마을, 무궁화호 등)까지만 줍니다. 이 프로그램은 `KTX`를 `KTX-1`로 바꿔 표시합니다 (`grade_labels`).
- 와인산천·청산천처럼 **어떤 편성이 들어가는지는 공식 공개 데이터가 없습니다.** 알고 있는 열차가 있으면 `config.json` 의 `train_vehicles` 에 직접 적으세요. 화면에 ✎ 표시가 붙습니다.

```json
"train_vehicles": { "101": "와인산천", "407": "청산천" }
```

## 6. 화면 구성 (레일보드)

- **시간표**: 역·시간대별 열차 목록. 열차를 누르면 오른쪽(폰은 새 화면)에 상세가 열립니다.
- **노선도**: 노선을 세로로 그리고 지금 달리는 열차를 올립니다. 실시간 위치는 서울시 API가 있는 수도권만 됩니다.
- **열차 상세**: 친구들이 올린 편성, 정차역 시간표(간선), 시간표 기준 현재 위치.
- **편성 모아보기**: 최근 올라온 편성 목록.

### 편성 공유
- 열차 상세의 「오늘의 편성」에 본 편성을 입력하면 `data/formations.json` 에 저장되고 모든 친구 화면에 바로 나옵니다.
- 👍가 가장 많은 편성이 그날 그 열차의 이름으로 시간표·노선도에 표시됩니다 (✎ 표시).
- 이름은 브라우저에 기억됩니다. 편성은 직접 보거나 탄 열차만 올려 주세요.
